# Sites — Portfólio

Sites de demonstração usados como base para projetos de clientes.

| Projeto | Nicho | Stack | Pasta |
|---|---|---|---|
| Prado Ribeiro Advocacia | Advocacia (família, trabalho, previdência) | React + TypeScript + Tailwind + Vite | [`Advocacia/hero-react`](Advocacia/hero-react) |
| Âmbar | Loja de roupas unissex (e-commerce: home com rolagem animada + página de produto) | React + TypeScript + Tailwind + Vite | [`Loja de Roupas - Ecommerce/loja-react`](<Loja de Roupas - Ecommerce/loja-react>) |

## Rodar um projeto

```bash
cd Advocacia/hero-react
npm install
npm run dev
```

> Conteúdos das demos (nomes, números de OAB, casos, depoimentos, produtos, preços e indicadores) são **fictícios/ilustrativos**.
