# Sites — Portfólio

Sites de demonstração usados como base para projetos de clientes.

| Projeto | Nicho | Stack | Pasta |
|---|---|---|---|
| Prado Ribeiro Advocacia | Advocacia (família, trabalho, previdência) | React + TypeScript + Tailwind + Vite | [`Advocacia/hero-react`](Advocacia/hero-react) |

## Rodar um projeto

```bash
cd Advocacia/hero-react
npm install
npm run dev
```
